Security Notes

  • Passwords are hashed with Werkzeug (never stored in plaintext).
  • Session-based authentication with Flask-Login.
  • Role-based authorization on every endpoint (/admin/*, /provider/*, /patient/*).
  • CSRF protection enabled on all POST forms.
  • Patients can only access their own appointments and profile.

Production checklist: set a strong SECRET_KEY environment variable, use HTTPS, and use a production WSGI server (e.g. gunicorn/waitress).
